# Said-No v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A hosted Sui consent firewall that remembers the sends a user rejected (Walrus Memory, mainnet) and escalates similar future sends using live Tatum chain facts.

**Architecture:** Next.js (server routes only) on Vercel. Pure TypeScript core (`features`, `engine`) with no I/O, wrapped by a Tatum gRPC client (reads, dry-run, execute) and a Walrus Memory layer. A baked replay fixture is the default view so the hosted page never goes dead.

**Tech Stack:** TypeScript, Next.js, Vitest, `@mysten/sui` v2 (`SuiGrpcClient`), `@mysten-incubation/memwal` 0.0.x, Node >= 22.23.4, pnpm.

**Spec:** `docs/superpowers/specs/2026-10-28-said-no-v2-design.md` (Tatum/Memory API findings also in `2026-10-28-hindsight-design.md`).

## Global Constraints

- Deadline 10 Nov 2026 17:00 UTC; no new features after day 11; submit day 12.
- Node >= 22.23.4; `@mysten/sui` v2 only (pin to the memwal peer range).
- gRPC-first against `https://sui-mainnet-grpc.gateway.tatum.io` with `x-api-key`; Sui JSON-RPC is decommissioned; fallback ladder: grpc-web, `@grpc/grpc-js`, Tatum GraphQL (`https://sui-mainnet.gateway.tatum.io/graphql`), shrunk check (balance + dry-run).
- Build and demo on MAINNET (Tatum testnet is gRPC-only; Storage API needs a mainnet key).
- Memory: mainnet relayer `https://relayer.memory.walrus.xyz`; `remember` returns `{job_id}` then poll `waitForRememberJob`; `recall({query, limit, namespace, sort})` returns `{results:[{blob_id,text,distance,created_at?}]}`; semantic only, so store features as a JSON line in the text and match in code; do not depend on `ask()`. Limits: 60 writes/min per account, 30/min per delegate key; Tatum free 3 rps.
- Similarity weights fixed and printed: recipient 0.35, amount 0.30, hour 0.20, interaction 0.15. Bands: <0.40 none, 0.40-0.69 reminder, 0.70-0.84 reflection, >=0.85 hold. Never call it ML.
- A denied send has no transaction; its proof is the Memory blob id. Delegate keys are account-wide read/write. Tatum failures fail closed (escalate, never allow).
- Source badges `real | seeded | demo` on every memory row; at least 10 (aim 12-15) REAL mainnet memories written by the submitted delegate key. Keys only in server env, never `NEXT_PUBLIC_*`, never committed or logged. Execute is gated by a server flag so visitors cannot spend.
- No "primarily built with ai.tatum.io" claim. MIT licence.

## Review Focus

1. Empty history or first-ever send: verdict `normal` with "learning (0)", never an error (Task 4).
2. One very similar past denial plus several matching approvals: approvals offset it; not a permanent blacklist (Task 4).
3. Malformed, truncated or foreign JSON returned by semantic `recall`: ignored and counted, never throws, never changes a verdict (Task 6).
4. Tatum 429 / timeout / credit exhaustion mid-check: result is `reflection` or higher with a "check unavailable" reason, never `normal` (Task 5).
5. Memory write rate-limited or failing: user sees a retry state and no decision is silently lost; a repeated click does not double-write (Task 6).

### Task 4: Engine, ladder, counterfactual (pure; the flip test)

**Files:**
- Create: `src/lib/engine.ts`, `tests/engine.test.ts`

**Interfaces:**
- Consumes: `Features`, `Decision`, `Level` from Task 3.
- Produces: `similarity(c: Features, d: Features): number` (= `0.35*m_recipient + 0.30*m_amount + 0.20*m_hour + 0.15*m_interaction`; `m_recipient = c.novelRecipient === d.novelRecipient ? 1 : 0`; `m_amount = 1 - min(1, |ln c.amountRatio - ln d.amountRatio| / ln 4)`; `m_hour` = 1 if both in night band 0-5 or both outside; `m_interaction` = 1 if same bucket {0, 1-2, 3+}); `evaluate(c: Features, recipient: string, decisions: Decision[]): Verdict` where `Verdict = {level: Level; score: number; matches: {decision: Decision; similarity: number}[]; counterfactualLevel: Level; reasons: string[]}`.
- Rules: only `deny` and `approve`/`override` count; `delete` removes the referenced decision; a `hard` denial for the same `recipient` returns `hold` always; matches are decisions with similarity >= 0.40; level base from the best denial similarity by the bands; if matching approvals >= matching denials, drop one level (floor `normal`); hold also requires at least 2 matching denials unless a hard memory applies. `counterfactualLevel = evaluate(c, recipient, []).level`.

- [ ] **Step 1: Write failing tests in `tests/engine.test.ts`:** empty history gives `normal` with reason "learning (0)"; one denial at similarity >= 0.70 gives `reflection` at best; five matching denials give `hold` with 5 `matches` and `counterfactualLevel === 'normal'`; deleting one denial lowers `score`; a dissimilar control send stays `normal`; three matching approvals against one denial yields `normal` (not a blacklist); hard memory on the recipient gives `hold`; `similarity` is symmetric and returns 1 for identical features and a value in [0,1] always.
- [ ] **Step 2: Run `pnpm test engine`. Expected: FAIL.**
- [ ] **Step 3: Implement `similarity` and `evaluate`** exactly per the rules above.
- [ ] **Step 4: Run. Expected: PASS. Step 5: commit** `feat: explainable similarity engine and friction ladder`.
