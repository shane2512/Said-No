## Thread

1/ Most wallets remember what you approved. Said-No remembers the sends you refused, and asks again when a new one looks the same. A consent firewall on Sui. [VIDEO]

2/ Deny a send and type why. The reason goes to Walrus Memory. Next time a similar send comes up, it quotes you back, adds friction in proportion to the match, and shows the counterfactual: normal without your memory, reflection with it.

3/ Tatum supplies the live facts over native Sui gRPC: balance, your own history, a dry run, a scam-list check. You can run a check with no wallet. A wallet is only needed to save a refusal or send. The server holds no spending key.

4/ No ML: fixed, visible weights, tuned a little by your own refusals. If Tatum or Memory is down it fails closed, never a quiet "normal".

5/ Honest notes: the 12 mainnet memories are drafted examples, one tiny mainnet send was verified on-chain, and much of the code was written with Claude Code.
